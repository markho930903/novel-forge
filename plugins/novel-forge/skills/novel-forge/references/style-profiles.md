# 文风卡

## 使用边界

文风卡约束读者能够观察到的表达选择，不承诺复刻某位作者或某部作品。用户提到现有作品时，把作品名转译成高层叙事特征，再使用下面的原创风格名称。

- 不复用原作句子、角色、地名、专有名词、情节、章节结构或可识别的独特表达。
- 不把“像某作品”当成完整风格定义；先拆成语体、叙事距离、句式节奏、对白声线、意象、幽默/恐惧机制和禁用项。
- 文风卡不覆盖世界规则、人物事实和时间线；内容因果优先，风格只改变呈现方式。

## 选择与持久化

1. 选择一个主文风，最多叠加一个辅助文风。没有明确要求时，使用自然、具体、克制的通用叙事，不擅自堆砌华丽辞藻。
2. 开书时生成一份“文风合同”，至少写明读者体验、叙述视角与距离、语体和时代词汇、句式节奏、意象范围、对白声线、常用手法和禁用项。
3. 写章、续写、改稿和审校时读取当前文风合同。长篇保存时，唯一落点是项目根目录的 `08_创作合同.md`，并在 `07_事实账本.md` 记录生效章节和切换原因。
4. 每次切换文风都记录生效章节或场景；不要在同一场戏中无理由切换语体、喜剧强度或叙述距离。

## 参照作品的高层转译

这些映射只用于把用户的模糊参照变成原创约束，不是模仿开关。

| 用户参照 | 转译到的原创文风 | 只提炼的高层特征 |
| --- | --- | --- |
| 《剑来》 | 古典诗性仙侠，可叠加江湖庙堂群像 | 山水行旅、修行与人情、含蓄留白、人物在具体选择中成长 |
| 《神秘复苏》 | 都市规则惊悚 | 可观察的异常规则、资源稀缺、逐步收紧的生存压力、有限安全空间 |
| 《雪中悍刀行》 | 江湖庙堂群像 | 多阵营人物、江湖与权力交错、克制的情感表达、选择带来的代价 |
| 《诡秘之主》 | 秘仪蒸汽悬疑 | 层级化知识、组织与身份、仪式条件、线索递进和信息差 |
| 《惊悚乐园》 | 黑色幽默游戏化冒险 | 任务化场景、荒诞反差、冷面吐槽、规则限制下的临场解法 |

## 风格档案

每张卡都同时规定“怎么写”和“不要写成什么”。具体句子仍须服务当前场景的目标、阻力和变化。

### 古典诗性仙侠

- 核心体验：苍茫山水、修行代价与人情选择并置，情绪留白多于直白宣告。
- 写法：使用清峻而可读的现代汉语，偶尔借用准确的古典词汇；以物候、器物、行路和动作承载境界，不靠连续警句证明深刻。
- 节奏：远景舒展，交锋收紧；长句负责气韵，短句负责决断，段落转折要对应人物选择。
- 对白：按身份、门第、地域和关系区分声线；高位人物少解释，市井人物可直白，但都必须有目的或信息差。
- 禁用项：生硬文言堆叠、现代网络热梗、无代价跳境界、只写风景不写选择、把哲理当口号。
- 自检：每场至少有一个具体阻力或代价，诗性描写删去后仍能看出人物做了什么。

### 轻快幽默与喜剧冒险

- 核心体验：笑点来自人物目标、性格缺口、身份错位或规则反差，而不是作者站出来讲笑话。
- 写法：先建立读者预期，再用行动或信息差转向；允许铺垫、停顿、回收和重复变奏，笑点之后保留对情节的影响。
- 节奏：对话短促、动作清楚；严肃场景降低玩笑密度，关键危险不被连续包袱抹平。
- 对白：每个角色的幽默方式不同，例如自嘲、冷面、夸张、误解或一本正经；避免所有人共享同一套吐槽口吻。
- 禁用项：段段抖机灵、网络梗替代人物、解释笑点、拿弱者或创伤本身当唯一笑料、笑完人物状态却没有变化。
- 自检：删去笑句后，场景的目标、阻力和关系变化仍成立；保留笑句后，至少有一处节奏或关系被改变。

### 江湖庙堂群像

- 核心体验：个人情义、门派立场和公共权力互相牵制，多个人物都拥有可理解的选择。
- 写法：用行动、旧债、礼数和利益展示人物，不用旁白给每个人贴正邪标签；让小事折射更大的制度或时代压力。
- 节奏：大局推进与近身细节交替；群像切换必须带来新信息、立场变化或代价，不能只换名字。
- 对白：同一事件在不同阵营口中有不同称呼和重点；沉默、避让和礼节也可以是有效行动。
- 禁用项：配角只为烘托主角、阵营立场随情节方便改变、人人都说同一种漂亮话、权谋只靠临场揭底。
- 自检：每个关键阵营至少有一个具体目标和不能轻易放弃的代价，人物选择能回溯到已知事实。

### 都市规则惊悚

- 核心体验：异常可被观察却不完全可控，熟悉的城市空间逐步失去安全感。
- 写法：先给征兆和可验证规则，再让角色试探、误判或利用；用值班表、监控、门禁、路线和物资把恐惧落到现实细节。
- 节奏：信息披露慢于危险逼近；短句承载即时反应，较长段落只用于整理证据或扩大未知。
- 对白：角色不能共享未知信息；专业人员讲条件，普通人讲感受，恐惧通过选择和失误显现。
- 禁用项：临时改写规则、无边界的万能异常、只靠血腥堆惊吓、角色突然知道答案、危险没有可理解的触发条件。
- 自检：每个反转前都有可回溯的征兆，安全空间、资源和幸存代价能逐项对账。

### 秘仪蒸汽悬疑

- 核心体验：知识本身带来力量和风险，身份、组织与仪式让真相层层变形。
- 写法：建立术语的边界和来源；用文件、传闻、实验、仪式和组织流程递进披露信息，保持线索的可靠性分级。
- 节奏：调查段落精确克制，揭示段落短而有后果；每获得一层知识，都改变角色对危险或自我的理解。
- 对白：不同组织有不同礼仪、术语和隐瞒方式；角色只依据自己的身份和已知信息行动。
- 禁用项：为了神秘而故意含混、谜底依赖从未出现的证据、力量没有代价、专有名词堆砌却不改变选择。
- 自检：每条关键线索有来源、可靠性、已知者和回收位置；每次仪式写清条件、代价和失败后果。

### 黑色幽默游戏化冒险

- 核心体验：危险、荒诞和规则任务同时存在，角色用清醒的目标感处理不合常理的场面。
- 写法：把场景拆成任务目标、限制、可用资源和失败后果；幽默来自目标与场面错位、角色反应或规则漏洞，不破坏世界因果。
- 节奏：任务节点清楚，战斗或解谜时快速，结算和余波时留出反讽；重复机制必须升级或变形。
- 对白：主角的冷静、队友的恐慌、系统或裁判的机械口吻要彼此区分；吐槽不能替代决策。
- 禁用项：为了笑点取消伤害、用作者旁白解释设定、规则只在失败后出现、每个角色都像同一个脱口秀演员。
- 自检：每个任务都有可验证的胜负条件和代价；笑点不会抹掉失败、伤势、关系或资源变化。

### 冷峻现实悬疑

- 核心体验：真相藏在普通人的利益、习惯和制度缝隙中，情绪压低但后果具体。
- 写法：少用全知判断，多用证词、记录、物件和行为矛盾；让推断随着证据收窄，不用巧合替代调查。
- 节奏：调查推进稳定，关键发现短促明确；留白用于不确定性，不用于隐藏作者尚未决定的答案。
- 禁用项：侦探凭直觉锁定唯一答案、关键证据最后才出现、反派只为恶而恶、用大段内心独白代替验证。

### 温暖日常成长

- 核心体验：关系、习惯和微小选择累积成可感知的改变，冲突不必升级成毁灭性事件。
- 写法：用饮食、空间、工作、天气和重复的小动作表现亲密与距离；每个温柔场景都留下具体变化。
- 节奏：允许慢，但每场都要改变关系、认知或下一步计划；幽默保持轻，不抢走人物的脆弱时刻。
- 禁用项：把善良写成无条件正确、用偶然奇迹解决关系、角色只围着主角服务、情绪只靠哭喊表达。

### 热血成长冒险

- 核心体验：目标明确，能力与伙伴关系通过选择和代价逐步升级，胜利带来新的责任而非只增加数值。
- 写法：每次突破都预先埋下训练、资源或理解上的准备；战斗用空间、体力、信息和取舍塑造胜负。
- 节奏：准备、交锋、反转、结算四段至少有一处状态变化；高强度段落之后给人物和读者恢复空间。
- 禁用项：临战领悟万能能力、敌人轮流送经验、只报技能名不写行动、胜利不改变关系或风险。

## 组合规则

- 主文风决定叙述语体和读者预期，辅助文风只改变局部压力或气氛。
- 组合必须写出冲突边界。例如“古典诗性仙侠 + 轻快幽默”可以让人物对白有反差，但不能让严肃世界规则随笑点失效。
- 题材机制卡决定世界如何运转，文风卡决定读者如何感受；两者冲突时先修正因果，再调整表达。
- 改稿时先修硬性矛盾，再按文风合同修语体、节奏、对白和意象；不要用“更有文采”替代具体修改。

## 文风闸门

每次输出前核对：

- 叙述视角、距离、时代词汇和段落呼吸是否与合同一致。
- 主要人物的对白是否可区分，幽默、恐惧或抒情是否由场景行动产生。
- 选定的意象和修辞是否具体、不过量，是否出现禁用的网络腔或空泛套话。
- 文风变化是否伴随明确的章节、场景或人物视角变化。
- 将作品名替换成风格标签后，正文是否仍然成立且保持原创。
